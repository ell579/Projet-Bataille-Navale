Ce projet est un jeu de bataille navale.

Pour jouer, rien de plus simple, il faut simplement lancer le main.py, une grille aléatoire de 8 par 10 va être générée avec les 4 bateaux de tailles différentes placés aléatoirement.

Il va ensuite falloir rentrer une ligne et une colonne, si c'est raté un 'x' apparaitra et si c'est touché une '💣' apparaitra. Enfin lorsqu'un bateau est coulé, il apparaitra.

Une fois tous les bateaux coulés, bravo vous avez gagné ! Il s'affichera donc le nombre de coups utilisés.

Bonne chance !
